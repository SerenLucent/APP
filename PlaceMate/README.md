# 지도메이트

신뢰하는 메이트들과 개인 장소와 경험을 선택적으로 나누는 모바일 대응 웹앱입니다.

네이버 지도 SDK와 NAVER API HUB의 실제 가게 검색 연결 코드를 추가했습니다. [키 발급·설정·요금 안내](NAVER_SETUP.md)를 참고하고, `npm run build:gas`로 생성한 `apps-script/Code.gs`를 배포합니다. 키 설정 전에는 임시 OpenStreetMap이 표시되며 실서비스 호출은 아직 검증되지 않았습니다.

GitHub `APP/PlaceMate`에 개인 원본과 방별 JSON을 저장하는 전용 서버 코드는 [apps-script/PlaceMate.gs](apps-script/PlaceMate.gs), 설정 안내는 [apps-script/README.md](apps-script/README.md)에 있습니다. 토큰은 Apps Script 스크립트 속성에 설정합니다. 사용자가 제공한 배포 주소는 `cloud-store.js`에 연결했습니다. 상단 ‘개인 저장소 연결’에서 새 개인키를 발급하거나 기존 키로 접속합니다. 미접속 상태의 메이트와 장소는 체험 예시이며 저장 작업에는 접속이 필요합니다.

## 실행

Node.js 20 이상에서 별도 패키지 설치 없이 실행합니다.

```sh
npm run dev
```

브라우저에서 http://localhost:4173 을 엽니다. 포트 변경은 `PORT` 환경변수로 지정합니다.

```sh
npm run check
```

## 구현한 기능

- OpenStreetMap 지도, 드래그 이동, 확대·축소, 장소 중심 이동, 카테고리·검색·방문 필터, 목록 보기
- 개인 장소 등록·수정·삭제, 방마다 선택 배포·전체 선택·공유 해제
- 장소 원본 수정 시 공유한 방에 반영, 새 장소는 개인 지도에만 저장
- 수동 방문 체크, 종합 별점, 자유로운 커스텀 평가 항목과 별점, 한 줄 평
- 메이트별 방문 표시 및 사람을 선택해 상세 평가 확인
- 방 생성, 초대 코드 입력과 가입 요청, 방장 승인·거절, 밴·해제, 방장 위임, 탈퇴
- 탈퇴·밴 시 해당 방의 공유만 제거하고 개인 기록과 다른 방의 공유 유지
- 브라우저 localStorage 저장, JSON 백업, 홈 화면 설치용 manifest와 서비스 워커
- 데스크톱 및 모바일 레이아웃

## 현재 범위

미접속 상태에서는 체험용 예시를 보여주며, 개인 저장소 연결 후에는 서버에서 읽은 본인 원본과 승인된 방 데이터로 교체합니다. 기존 체험 데이터는 자동 업로드하지 않습니다. 인증은 32바이트 개인키 기반이며 이메일 로그인이나 키 분실 복구는 아직 없습니다. 개인키는 브라우저에 보관하고 파일로 백업할 수 있습니다. 다른 기기에서 같은 키로 기존 기록을 불러옵니다. JSON 백업은 내보내기만 제공합니다.

다른 사람의 장소를 내 지도에 저장하면 독립된 개인 원본을 만들고 공통 `canonicalId`를 유지해 방문 기록을 재사용합니다. 방 지도에서는 같은 공통 ID를 하나의 핀으로 묶습니다. 외부 장소 검색·주소 좌표 변환과 서로 독립적으로 신규 등록한 장소의 동일성 판별은 아직 연결하지 않았습니다. 장소 검색은 저장된 장소 내 검색이며 신규 좌표는 직접 입력합니다.

개인 저장·방 공유·가입 승인·밴·위임은 Apps Script 서버에서 권한을 검사합니다. 버전 충돌이나 저장 결과가 불확실한 요청은 성공으로 표시하지 않고 서버 새로고침 후 재확인하도록 안내합니다. 실시간 자동 수신은 없으며 상단 서버 새로고침으로 다른 메이트의 변경을 가져옵니다. 소규모 운영용으로 Apps Script와 GitHub API 제한을 받습니다.

투플레이스와 같은 `SerenLucent/APP`의 `main` 브랜치에 GitHub JSON을 저장하며, 저장 경로만 `PlaceMate/`로 구분합니다. 공개 저장소 검사로 접근을 차단하던 조건을 제거했습니다. 최신 `PlaceMate.gs`를 기존 Apps Script 배포의 새 버전으로 적용해야 실제 서버에 반영됩니다. `GITHUB_TOKEN`은 스크립트 속성에 두고, 저장소·계정·브랜치는 투플레이스와 동일한 기본값을 사용합니다. 공개 저장소의 JSON 자체는 GitHub에서 공개됩니다. 웹앱의 정적 HTTPS 배포와 APK 제작은 별도입니다.

## 지도 및 설치

현재 지도는 OpenStreetMap 공개 타일을 사용하며 attribution을 표시합니다. 운영 배포 시 예상 사용량에 맞는 타일 제공 서비스와 이용 정책을 확인해야 합니다. 지도와 웹폰트는 네트워크 연결이 필요합니다. 서비스 워커는 앱 셸만 캐시하며 오프라인 지도를 제공하지 않습니다.

아이폰에서는 HTTPS 배포 후 Safari의 공유 → 홈 화면에 추가로 실행합니다. 실제 아이폰에서의 설치 검증은 아직 수행하지 않았습니다. Android에서도 설치 가능한 PWA를 목표로 구성했으며 실제 배포 전 PNG 앱 아이콘과 기기별 설치 검증이 필요합니다.

APK는 아직 생성하지 않았습니다. 안정적인 HTTPS 웹 주소를 배포한 다음 TWA와 Digital Asset Links 또는 전용 WebView 앱으로 패키징해야 합니다. 일반 웹페이지에 한 번 방문했다고 APK 설치·자동 실행이 되는 것은 아니며, 사용자의 앱 설치가 필요합니다.
