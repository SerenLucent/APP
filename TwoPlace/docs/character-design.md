# 모모·쿠키 캐릭터 디자인 기준

## 쿠키 — 사용자 확정 (2026-10-23)

- 꼬리 **끝**에 달린 **큰 노란 별 하나**가 쿠키의 시그니처다. 모든 방향에서 유지한다.
- 예전에 제거 요청한 것은 꼬리 **중간**에 박힌 별이었다. 꼬리 끝의 큰 별을 제거하거나 작은 별로 바꾸라는 뜻이 아니다.
- 귀에는 별을 추가하지 않는다.
- 새 포즈를 만들 때 몸의 각도만 바꾸고 이 특징, 보라색 털, 크림색 주둥이와 배, 짧은 다리를 유지한다.

## 움직임

정면·뒷면·옆면·대각선 앞·대각선 뒤의 포즈에 좌우 대칭을 조합해 화면 기준 8방향을 표현한다. 이동 각도는 45도 구간으로 선택한다.

## 생성 기록

기본 제공 image_gen 도구로 대각선 스프라이트를 생성했다. 최종 파일:

- public/pets/mochi-diagonal-front-v1.png
- public/pets/mochi-diagonal-back-v1.png
- public/pets/kuki-diagonal-front-v3.png
- public/pets/kuki-diagonal-back-v3.png

모모 최종 프롬프트 기준: 기존 정면·뒷면을 참조해 동일한 크림색 털, 분홍 귀 끝과 하트 새싹, 짧은 다리, 서 있는 비율을 보존한다. 고정 카메라에서 몸 전체를 오른쪽 아래 방향의 앞 3/4, 오른쪽 위 방향의 뒤 3/4로 돌린다. 정사각형 투명 배경, 중앙 배치, 소품·문자·바닥 그림자 없음.

쿠키 최종 편집 프롬프트: 대각선 원본의 몸 각도·비율·털·발·카메라를 보존한다. 기존 kuki-side-v3.png와 kuki-back-v3.png를 형태 기준으로 사용한다. 보라색으로 말린 꼬리의 자유로운 끝에서 큰 노란 오각별 하나가 이어지며 바깥 윤곽을 이룬다. 기존 옆모습과 같은 크기(캔버스 폭 약 18%)의 푹신한 별이다. 꼬리 중간에 박힌 패치·문양·장식이 아니며, 귀의 별·추가 별·줄·체인은 만들지 않는다. 투명 배경을 유지한다.
