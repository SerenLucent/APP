# 가구 사용 모션

로컬 검토: /furniture-motion-review.html

- 이미지 생성: 내장 image_gen, 투명 PNG 아틀라스 2장.
- 기준 이미지: public/pets/mochi-standing-v2.png, kuki-standing-v2.png.
- 프롬프트 1: 두 캐릭터의 앉기와 잠든 눕기, 각각 SE/SW/NW/NE 4방향을 4×4 아틀라스로 제작. 부드러운 털과 얼굴, 모모 하트 새싹, 쿠키 꼬리 끝에 달린 큰 노란 별 유지. 가구·문자·그림자 없이 투명 배경.
- 프롬프트 2: 같은 두 캐릭터의 서서 손 뻗기와 앉아서 물건 들기, 각각 4방향을 같은 4×4 아틀라스로 제작. 소품과 가구는 제외.
- 결과: public/pets/furniture-poses-v1.png, public/pets/interaction-poses-v1.png.
- 의자/침대 위치와 높이는 가구 모델의 셀 좌표와 같은 단위로 계산. 서 있는 이미지를 회전해 눕히지 않음.
- 앉기/눕기는 전용 자세와 호흡 반복, 다른 동작은 손 뻗기와 소품 반복 연출. 각 가구마다 별개의 프레임 애니메이션을 만든 것은 아님.
- 시간 제한 동안 같은 펫 화면 재렌더는 유지, 방 변경 및 직접 이동 시 해제.
