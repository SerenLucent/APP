# 별잠산 로컬 액션 프로토타입

실행: npm run build 후 npm run preview -- --port 5178
주소: http://127.0.0.1:5178/adventure.html

- WASD/방향키 또는 왼쪽 조이스틱 이동. 맵 터치 이동도 지원.
- J 공격: 앞발/짧은 꼬리 스윙. 스태미나 소모 없음.
- Space 또는 차지 버튼 누르기 → 놓으면 발동. 차지 중 속도 50%.
- 모모: .65~5초 회전. 도중 중단/교체 불가. 방향 조절 가능.
- 쿠키: 기존 방향별 스프라이트로 몸을 한 바퀴 회전, 꼬리 타격 한 번. 꼬리를 늘이거나 별도 준비 모션을 사용하지 않음.
- 차지 비용 8~60. 보유 스태미나 한도까지 충전. 준비 1초 이후 2.4초 충전, 총 3.4초. 준비 중 놓으면 소모 없이 취소.
- Q 교체. 대기 HP +3/s, 스태미나 +2%/초. 출전 중 비공격 상태 스태미나 +1%/4초.
- 가시덤불 HP 피해. 쓰러진 친구는 회복 불가. 둘 다 쓰러지면 재시작.
- 나무 HP45, 바위 HP160. 폐가에 도착하면 완료. 로컬 세션만, 실제 방/하트와 무관.

이미지 초안: imagegen 내장 도구로 3x2 차지/회전 시트를 시도했으나, 후속 요청(쿠키 기존 모습으로 한 바퀴 회전)에 따라 게임에는 미사용.
보관 위치: docs/adventure-art-drafts/action-atlas-unused.png
프롬프트 요약: 기존 모모/쿠키 플러시 질감 유지, 위 3칸 모모 차지/정면 회전/후면 회전, 아래 3칸 쿠키 몸 회전/꼬리 스윙, 3x2 동일 셀, 투명 배경. 꼬리 끝에만 큰 별. 최종 게임은 public/pets의 기존 5방향 이미지를 순차 전환해 8방향 회전을 표현.

모모 회전 전용 아트: public/adventure/momo-spin-v1.png. imagegen 내장 편집 도구로 원본 시안의 정면 사선/뒷면 사선 2포즈를 투명 2칸 스트립으로 제작. 두 포즈를 각각 좌우 반전해 4프레임 순환. 쿠키는 기존 방향별 이미지를 유지.

## 스킬 게이지 / 태그 연계
- 각 캐릭터 공격 1회가 실제로 적중하면 게이지 +10. 다중 적중도 한 번의 공격에는 +10. 허공 공격와 차지/게이지 스킬은 충전하지 않음.
- 캐릭터별 100에 중앙 버튼 또는 E로 사용. 스태미나 비용 없이 게이지 전체 소비, 연속 중복 발동 차단.
- 모모 하트 팡: 주변 이동 가능한 자리로 하트 5개. 쿠키만 줍기. 필드 하트 30초 유지, 최대 30개.
- 하트: 쿠키 공격/꼬리 차지 피해 +20%. 개당 지속시간 +10초, 최대 90초. 배율 중첩 없음. 쿠키 대기/일시정지 시 강화 시간 정지.
- 쿠키 별똥별 쿵: 1초 점프·착지 연출, 반경190 내 물체의 현재 HP 절반. 강화 배율 적용하지 않음. 낙하 중 이동/차지/교체 금지.
- 중앙 게이지 버튼 및 캐릭터 HUD에 현재 스킬 게이지 표시. 강화 중 쿠키 HUD 남은 시간 표시.

밸런스 조정: 같은 스태미나60 기준 모모 풀차지 5초, 0.32초당7 피해(대상당 최대 약112). 쿠키 풀차지300 피해, 하트 강화 중360. 모모 판정 반경104+대상반경, 쿠키78+대상반경으로 좁힘.

## 숲 방울이 적 AI
- 6마리 배치. 대기 → 추격 → 귀환 → 대기. 시작 지점은 감지 범위 밖.
- 감지240, 타깃 이탈350, 원래 자리 기준 추격 한계440. 귀환 완료 전 재추격 금지.
- 40단위 8방향 A* 경로 탐색. 대각선 모서리 통과 차단, 나무/바위 충돌 반경 포함. 0.65초마다 갱신.
- 가까이46에서 0.55초 준비 표시 후 공격. 맞을 때 거리58 이내만 HP10 피해. 공격 간격1.25초, 플레이어 피격 무적1초.
- 공격/차지/스킬은 적에도 적용. 공격 적중으로 스킬 게이지 획득. 처치한 적은 재시작 전까지 재등장하지 않음.
- 원래 자리 복귀 후 피해 입은 HP는 유지. 일시정지 중 AI 중단.

## 영구 성장·클리어 보상
- 커플방 저장 경로: 기존 room.json의 petHome.adventure. hpPotions/staminaPotions/points는 공유, stats.momo/stats.kuki는 별도.
- 연결된 방이 없는 로컬 미리보기는 브라우저의 독립 테스트 재화로 저장. 실제 방 토큰이 있으면 기존 /room/pets 인증 API로 저장. GAS 배포 전에는 실제 방에서 새 액션을 처리할 수 없음.
- 물약은 최대 HP/SP의 50% 회복, 최대치 이상 회복 불가, 한 번에1개. 좌하단 버튼에 보유 수량 표시.
- 힘/체력/스태미나/운/손재주 각각 투자 상한100. 체력·스태미나1당 최대치+5. 힘1당 최소+1/최대+2. 운1당 치명타확률+.5%p. 손재주100은 항상 최대 일반 피해.
- 기본 공격: 모모8~15, 쿠키10~20. 기본 치명타 확률 모모10%, 쿠키5%. 치명타2배. 일반 피해 흰색/테두리, 치명타 노란색/테두리/2배 크기.
- 100개 완료 즉시 보상과 클리어 기록 저장. 룰렛 버튼은 저장한 보상을 연출로 공개. 같은 판/요청 재전송으로 재지급되지 않음.
- 누적 클리어는 커플 공동. 새 판의 적 수 =24+floor(totalClears/20)*4. 진행 중인 판의 적 수는 시작 시 고정.
- 모든 클리어 이력 유지: 회차, 역할, 마지막 캐릭터, 시작/완료 시각, 장애물 수, 적 수, 실제 플레이 시간(일시정지 제외), 보상·등급. UI20개씩 추가 조회, 최고시간 표시.
- S <=5분, A <=8분, B <=12분, C >12분. 각 룰렛은 동일확률12칸.
  - S: ♥5×4 / ♥3×2 / 스탯+2×4 / HP약×1 / SP약×1
  - A: ♥5×3 / ♥3×2 / 스탯+2×4 / ♥1×1 / HP약×1 / SP약×1
  - B: ♥5×2 / ♥3×2 / 스탯+2×4 / ♥1×1 / HP약×1 / SP약×2
  - C: ♥5×1 / ♥3×1 / 스탯+2×4 / ♥1×2 / HP약×2 / SP약×2
- 완료 검증은 현재 프로토타입에서 서버 발급 판 번호·해당 필드의 서로 다른 장애물100개·1회 보상 여부를 검증. 클라이언트 전투/이동 전체를 서버에서 재연산하는 방식은 아님.
- 검증 전용 화면: adventure-progression-review.html. 가상 포인트3, 물약 각2개로 UI를 검증하며 실제 커플방에 접근하지 않음.

차지/스태미나 분리: 준비1초+충전2.4초 게이지는 잔량과 무관하게100%까지 충전. 모모 목표 지속시간에 맞춰 초당 소모하며0에 조기종료. 쿠키는 요구 스태미나 대비 실제 사용 비율로 기본 위력 축소. 예: 풀차지 필요60, 보유20이면 기본 위력300→100.
